Draft for the GitHub release of `v0.1.1-preview`. The owner fills in the SHA-256 table and the run id

---

**Project S.K.E.P.I. Developer Preview `v0.1.1-preview`: for developers and testers. Not for emergency use.**

S.K.E.P.I. (Survival Knowledge & Emergency Pocket Intelligence) is an offline knowledge and emergency
app. It offers Wikipedia search and sealed article reading, answers built from source excerpts with an
optional on-device AI summary, maps and places, emergency numbers and tools, and sharing packs between
devices. It has no accounts, analytics or telemetry.

> **Emergency cards are under professional review.** They ship without their steps ("Under professional
> review") until certified first-aid instructors have reviewed them; each card shows the emergency
> numbers. In an emergency, call your local emergency number.

```sh
sha256sum -c SHA256SUMS.txt                       # Linux / macOS / Git Bash
Get-FileHash .\SKEPI_0.1.1-preview_x64-setup.exe  # Windows PowerShell; compare with SHA256SUMS.txt
apksigner verify --print-certs skepi-0.1.1-preview-arm64.apk
```

## What changed since 0.1.0-preview

- **Name:** the product is now written **S.K.E.P.I.** on the phone's home screen, in the window title,
  About screens, problem reports and store texts. Package names and file names stay `skepi`/`SKEPI`.
- **Safer source excerpts:** Unicode look-alike and hidden characters no longer get past the source
  checks; links and e-mail addresses in excerpts show "[link removed]"; quoted instructions to an AI are
  removed like direct ones; on emergency questions, a phone number inside an excerpt is flagged "Number
  from a source — use the emergency number shown above".
- **Problem reports (Android):** "Report a problem with this answer" takes your description and opens
  the phone's share menu with the report. S.K.E.P.I. itself sends nothing and needs no new permission.
- **Secure storage:** if the phone refuses the database key, the app shows "Secure storage unavailable"
  with Retry instead of a blank screen; it never opens the database another way.
- **Reproducible Android build:** CI builds the unsigned APK twice on different runners and paths and
  checks they are byte-identical; F-Droid's `fdroid build` of the recipe gives the same bytes.
- **Store readiness:** F-Droid metadata, screenshots and recipe; every Expo module is built from source.
- **Apple builds in CI** (not released): iOS Simulator app and macOS desktop app, unsigned.

## Known limitations

- Developer Preview: tested on a Samsung Galaxy S23 (Android 16) and Windows 11 x64 only. English only.
  Greece map only.
- Source excerpts are shown verbatim: a wrong or misleading sentence in a pack is shown as written.
  Source integrity relies on the signed catalog of official packs.
- AI summaries can be wrong: check the cited excerpt. Emergency questions get no AI summary.
- Windows installers are unsigned; no automatic updates.
